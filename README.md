## Алгоритм решения
1. **НАЧАЛО**
2. Объявление переменных: `symbol` (символ), `h` (высота), `b` (верхнее основание), `a` (угол наклона), `repeat` (флаг продолжения).
3. Вывод "Введите символ из которого будет строиться фигура: ".
4. Ввод значения `symbol` с клавиатуры.
5. Вывод "Введите высоту (h): ".
6. Ввод значения `h` с клавиатуры.
7. Вывод "Введите ширину верхнего основания (b): ".
8. Ввод значения `b` с клавиатуры.
9. Вывод "Введите угол наклона (a): ".
10. Ввод значения `a` с клавиатуры.
11. Вызов функции `draw_trapezoid(symbol, h, b, a)`.
12. Вызов функции `ask_continue()` для получения ответа пользователя.
13. Проверка: если `repeat != 0`, переход обратно к шагу 3 (повторный ввод).
14. **КОНЕЦ**
